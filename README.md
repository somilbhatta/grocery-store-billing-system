## project Title
*Grocery Store Billing System

## Overview of the project
*A lightweight command-line interface application for managing  grocery-store billing.

## Features:

- Add products to the cart.
- Store product name, price, and quantity.
- Display all products in the cart.
- Calculate the amount of each product.
- Calculate the total bill.
- Apply discount based on the total amount.
- Generate the final bill.
- Exit the program through a menu option.

## Prerequisites
* Python3 installed on your system.
* No external libraries required.

## Python Concepts Used
-Lists
-Dictionaries
-Functions
-if-elif-else
-for and while loops
-User input
-Arithmetic operation

## Functions Used:

add_items()
Adds a new product to the grocery cart.

view_items()
Displays all products currently stored in the cart.

get_total()
Calculates and returns the total amount of all products.

add_discount(total)
Calculates the discount according to the total bill.

final_bill()
Calculates and displays the final bill after applying the discount.
